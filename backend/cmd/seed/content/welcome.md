# Welcome to self-docs

self-docs is your self-hosted knowledge base. Everything is written in
**Markdown** and organized into four sections.

## The four sections

1. **Workflows & Guides** — standard procedures and step-by-step guides.
2. **Project Notes** — nested documentation, like Docusaurus.
3. **Cheat Sheets** — quick references and snippets.
4. **Private Archive** — confidential notes behind a master password.

## Next steps

- Create your first document from **Documents → New document**.
- Import existing `.md` files with the **Import** button.
- Try the global search in the header.
