# Routing

The SPA route map lives in `src/routes.ts`:

- `/` dashboard
- `/documents`, `/workflows`, `/cheat-sheets`
- `/knowledge-base` (Project Notes)
- `/private`, `/search`, `/settings`
- `/documents/:id`, `/editor`, `/editor/:id`
